### [NSOS](https://codeberg.org/shirodev/NSOS)

**Needy Streamer Overload-inspired hobby operating system**

Early WIP OS for Raspberry Pi boards. Framebuffer output, drawing primitives (circles, rectangles, lines, pixels), UART, and custom fonts via bmpMaker. Supports ARM32 and AARCH64 RPI boards. x86-64 Limine support is planned.

[![View on Codeberg](https://img.shields.io/badge/View_on-Codeberg-fe89d9?style=for-the-badge&logo=codeberg&logoColor=white)](https://codeberg.org/shirodev/NSOS)
[![View on Codeberg](https://img.shields.io/badge/View_on-Github-fe89d9?style=for-the-badge&logo=github&logoColor=white)](https://github.com/kokovt/NSOS)
[![Language](https://img.shields.io/badge/Language-C-8e6bff?style=for-the-badge&logo=c&logoColor=white)](https://codeberg.org/shirodev/NSOS)
[![License](https://img.shields.io/badge/License-AGPL--3.0-14c8f9?style=for-the-badge)](https://codeberg.org/shirodev/NSOS/src/branch/main/LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Raspberry_Pi-fe89d9?style=for-the-badge&logo=raspberrypi&logoColor=white)](https://codeberg.org/shirodev/NSOS)

**Highlights**
- Tested on physical hardware: Raspberry Pi 400 and Pi 0W
- QEMU emulation support for development
- Multi-arch roadmap: ARM32, AARCH64, x86-64, x86

*Not affiliated with WSS playground or Microsoft.*
